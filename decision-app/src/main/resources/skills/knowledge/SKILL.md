# Knowledge Skill

Use this skill when the user asks about product documentation, operating manuals, FAQs, policy rules, or technical documents.

Call `knowledgeSearchTool` when the answer depends on repository content. Ask for a knowledge base code when the request cannot be scoped. Summarize retrieved material clearly and say when the search result is insufficient.
