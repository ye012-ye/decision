# Data Skill

Use this skill when the user asks for structured data, cache values, table fields, SQL queries, or business metrics.

Prefer metadata tools before writing a query when table structure is unknown. Use read-only query tools unless the user explicitly asks for a write operation and the tool supports it. Explain query assumptions and keep returned data focused.
